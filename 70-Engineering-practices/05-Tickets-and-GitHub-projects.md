# Issues and project board

Track work in documentation-repository issues on [Gym Buddy Project](https://github.com/orgs/Projet-de-compensation-2025-2026/projects/1). Use the existing board and issue form.

Each issue identifies the affected repository, functional/specification IDs, relevant documentation or mockup, acceptance criteria and verification evidence. Link the implementation pull request to its issue.

Use `Not Ready`, `Todo`, `In Progress` and `Done` to reflect actual readiness and completion. A passing local build alone does not close an issue requiring deployed browser behavior.

Commit scopes use verified issue numbers according to [Git workflow](02-Git-workflow.md). Keep longer explanations and cross-repository links in the issue or pull request, rather than adding commit-message footers.
