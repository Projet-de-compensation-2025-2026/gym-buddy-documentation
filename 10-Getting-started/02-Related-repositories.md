# Repositories

| Repository | Responsibility |
| --- | --- |
| [gym-buddy-documentation](https://github.com/Projet-de-compensation-2025-2026/gym-buddy-documentation) | Requirements, mockups, architecture, algorithms, test plans and academic deliverables |
| [gym-buddy-openapi](https://github.com/Projet-de-compensation-2025-2026/gym-buddy-openapi) | Versioned API schemas |
| [gym-buddy-service](https://github.com/Projet-de-compensation-2025-2026/gym-buddy-service) | Java backend, data migrations, fixtures and deployment |
| [gym-buddy-ui](https://github.com/Projet-de-compensation-2025-2026/gym-buddy-ui) | Angular member and staff applications |

The service and UI consume a pinned published OpenAPI revision. Build commands and tool versions live in their repository READMEs and manifests. [Environment and delivery](04-Environment-and-pipeline.md) describes the shared deployment model.

Verify examiner access and repository visibility against the school brief before delivery. Do not infer private access from an organization URL or assume that a tag has been deployed.
