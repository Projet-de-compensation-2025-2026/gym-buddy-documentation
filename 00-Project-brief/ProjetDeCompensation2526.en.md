## Overview

As part of your academic compensation project (5 ECTS), the project will cover the following modules: Software Engineering, Web Technologies, Algorithms and Advanced Programming.

The aim of the project is to connect athletes (example: fitness practitioners) so they can train together, motivate each other, and find their "gym buddy". Here is a non-exhaustive list of features:

- Friends news feed
- Posts, Repost, Like a post or a comment
- Creation of an instant or recurring event, public or private.  
  Example: a user proposes a weightlifting session open only to their friends, at a given location, for a given duration, at a specific time, with limited spots. Interested users can apply and the organizer accepts or declines
- Comments, nested over several levels
- Add a friend, approval required
- Private or public user profile
- Advanced search with parameters
- Personalized friend suggestions (the algorithm used must be justified)
- User account creation and administration
- Creation of admin / moderator accounts
- Instant messaging: private text, images, and audio recordings
- JWT authentication
- Security and controlled access for all files
- Creation of thousands of test fixtures
- Image management: avoid running out of local storage space

## Specifications / Tasks

To complete this project, you must follow this procedure:

- Discuss and scope the project with the instructor

  - friend suggestion algorithm

- A critical analysis of your solution, and possible improvements
