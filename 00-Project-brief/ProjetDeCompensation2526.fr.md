## Présentation générale

Dans le cadre de votre projet de compensation académique (5 ECTS) le projet couvrira les modules suivants : Génie logiciel, Technologies Web, Algorithme et Programmation avancés.

Le projet a pour but est de mettre en relation les sportifs (Exemple : pratiquants de fitness) afin qu'ils puissent faire leur séance ensemble, se motiver mutuellement et trouver leur "gym buddy". Voici une liste non exhaustive des fonctionnalités :

- Fil d'actualité des amis
- Posts, Repost, Liker un post, un commentaire
- Création d'un évènement instantané ou périodique, publique ou privé.  
  Exemple : un utilisateur propose une séance de musculation ouverte uniquement à ses amis, dans un lieu donné, pour une durée donnée, à une heure précise et avec des places limitées. Les intéressés pourront postuler et il acceptera ou non
- Commentaires, sur plusieurs niveaux
- Ajout d'ami, validation requise
- Profil utilisateur privé ou public
- Recherche avancée avec paramètres
- Proposition d'amis personnalisée (algorithme utilisé à justifier)
- Création et administration de compte utilisateur
- Création de comptes admin / modérateurs
- Messagerie instantanée : texte, images et enregistrements audio privés
- Authentification JWT
- Sécurisation et accès réglementé pour tous les fichiers
- Création de milliers de fixtures de test
- Gestion des images : éviter un manque d'espace de stockage en local

## Spécifications / Tâches

Pour réaliser ce projet, vous devez suivre la procédure suivante :

- Discuter et cadrer le projet avec l'enseignant
- Écrire les spécifications fonctionnelles et techniques de votre projet
- Fournir les différents diagrammes UML :
  - cas d'utilisation, activité, séquence
  - classes, etc.
- Concevoir et écrire les algorithmes nécessaires. Exemples :
  - algorithme de suggestion d'amis
  - recherche filtrée
  - matching utilisateurs
- Concevoir et implémenter la solution (Backend, Frontend et Back-office)
- Fournir un plan de test (fonctionnels, unitaires, d'intégration) raisonnable de votre solution
- Écrire des tests unitaires notamment pour le backend
- Une analyse critique de votre solution, des améliorations possibles
- Justifier vos choix de librairies
