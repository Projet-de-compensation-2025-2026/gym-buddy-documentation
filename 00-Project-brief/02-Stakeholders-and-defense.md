## Defense

| Slot | Duration | Purpose |
| --- | --- | --- |
| Presentation | 20 minutes | Product demo + architecture + algorithms + choices |
| Questions | 30 minutes | Instructor Q&A |

Format: in person **or** remote.

A 20-minute talk cannot cover every spec page. The presentation must pick a spine:

1. Problem and users
2. Live (or recorded) walkthrough of the major features
3. Architecture and data model
4. One algorithm in depth (suggestions or matching)
5. Security (JWT + file access)
6. Tests and honest limitations

Slide-by-slide plan: [../99-Academic-deliverables/02-Presentation.md](../99-Academic-deliverables/02-Presentation.md).
